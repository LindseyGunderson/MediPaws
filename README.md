# MediPaws

MediPaws is a veterinary clinic operations dashboard designed to help clinic staff manage appointments, patients, and pet owners from one place.

The project focuses on creating a practical admin experience with clear information hierarchy, reusable UI patterns, and responsive interactions.

## Highlights

- Dashboard showing daily appointment activity and upcoming appointments
- Appointment search and status filtering
- Appointment detail views with state-based actions
- Patient and owner profiles with related pet and appointment information
- Reusable components for appointments, patients, pets, status badges, and navigation
- Responsive layouts designed for common clinic workflows
- Accessible UI patterns and keyboard-friendly interactions

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Lucide Icons
- Vite

## What I Focused On

This project gave me an opportunity to work across both **frontend engineering and product design**.

Some of the areas I focused on include:

- Designing information hierarchy for an admin-focused application
- Building reusable React components and shared UI patterns
- Creating state-driven appointment workflows
- Designing responsive layouts across dashboard, list, and detail views
- Handling empty states, filtering, and conditional UI
- Considering accessibility and interaction states throughout the interface

## Project Status

MediPaws is an ongoing portfolio project.

The current version focuses on the core clinic dashboard, appointment management, and patient/owner experiences. Additional functionality, including persistent data and appointment creation/editing workflows, is planned as the project develops.
